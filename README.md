# 🧪 Simulation and Parameter Estimation - Polycondensation Reactor

A robust kinetic and thermodynamic simulator developed in Python for batch polycondensation reactors. The software integrates Differential Algebraic Equations (DAEs) for mass balance and performs kinetic parameter estimation using global (Particle Swarm/Differential Evolution) and local (Levenberg-Marquardt) optimization algorithms.

Originally written in segmented Fortran files, the project has been completely refactored into a modular Python architecture. Now, the simulation of multiple carbon chains (C6, C7, C8, C10) and the reactor's phase transitions are controlled from a single configuration file.

## ✨ Key Features

* **Integrated Phases:** Supports both **Esterification** (atmospheric pressure) and **Transesterification** (vacuum application with a sigmoid curve for realistic pump opening dynamics).
* **Chemical Database:** Instant switching between compounds (C6, C7, C8, C10) through a dynamic dictionary. Molar masses, densities, and vacuum pump parameters are adjusted automatically.
* **Modern Mathematical Solutions:** Replaced legacy solvers (`dassl.f`) with stiff numerical integrators (`scipy.integrate.solve_ivp` using the BDF method) and implemented numerical safety locks to prevent thermodynamic overflows.
* **Graphical Output:** Automatic generation of validation plots comparing the model's computed data with experimental laboratory samples at the end of the estimation process.

---

## 📂 Project Architecture

The logic has been divided into distinct modules to facilitate maintenance and version control by the engineering team:

* `config.py`: The reactor's control panel. Defines the version (e.g., 'C6'), the operational phase (0 or 1), and stores the physical properties database.
* `main.py`: The orchestrator. Initiates data reading, calls the optimization routines, and plots the results.
* `reator_dae.py`: The physical "engine". Contains the state equation derivatives and the time integrator.
* `cinetica.py` & `termodinamica.py`: Auxiliary modules containing rate laws, polymerization degrees, and Antoine / Flory-Huggins equations.
* `otimizacao.py`: Handles residue calculation and applies the `scipy.optimize` package.
* `utils.py`: Processes the parsing and reading of legacy laboratory data files (`.dat`).

## 🚀 Installation and Environment Setup (pyenv)

To ensure the scientific libraries run on the correct versions without interfering with your operating system, we highly recommend using `pyenv` and `pyenv-virtualenv`.

### 1. Prerequisites
Make sure you have [pyenv](https://github.com/pyenv/pyenv) and [pyenv-virtualenv](https://github.com/pyenv/pyenv-virtualenv) installed on your machine.

### 2. Setting Up the Environment
Open your terminal in the project's root folder and run the following commands:

```bash
# Install the required Python version (3.10 or higher is recommended)
pyenv install 3.11.7

# Create a dedicated virtual environment for the reactor
pyenv virtualenv 3.11.7 polymer-reactor

# Activate the virtual environment locally for this specific folder
pyenv local polymer-reactor
```

3. Installing Dependencies
With the environment activated (you should see (polymer-reactor) in your terminal prompt), install the necessary scientific libraries:

```bash
pip install numpy scipy matplotlib
```
(Optional: you can run pip freeze > requirements.txt to save the exact installed versions for future deployments).

🖥️ How to Use
Step 1: Insert Experimental Data
Place the experimental data files generated by the laboratory (dadosexp.dat and exp.dat) in the same directory as the Python scripts.

Step 2: Configure the Experiment
Open the config.py file and edit the global variables at the top according to your current trial:

Python
```bash
# GLOBAL EXPERIMENT CONFIGURATION
VERSAO_ATUAL = 'C6'  # Available options: 'C6', 'C7', 'C8', 'C10'
IMOD_ATUAL = 1       # 0 = Esterification, 1 = Transesterification
```
Note: When running the Esterification phase (IMOD = 0), make sure to update the parameters in the Epar tuple inside config.py with the optimal values found by the terminal before moving on to the Transesterification phase (IMOD = 1).

Step 3: Run the Simulation
In the terminal, ensure your pyenv environment is active and run:
Example for EtretificacaoFechadoC10:
```bash
cd .\ESTIMA_ESTERIFICACAOFECHADOC10\
cd .\Estimacao\
python main.py
```
The terminal will print the Differential Evolution steps, perform the Gauss-Newton refinement, display the Optimal Parameters, and open a window with the validation plot.
